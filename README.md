# ZPAINT

Automotive detailing, wrap, PPF & modification — Hong Kong.

## Stack

Pure static HTML / CSS / JS. No build step required.
Deployed on Vercel via GitHub integration.

## Structure

```
.
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Local preview

Just open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

Pushes to `main` are auto-deployed by Vercel.
