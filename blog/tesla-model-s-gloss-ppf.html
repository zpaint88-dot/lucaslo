今次入場嘅係一部深藍色 Tesla Model S，車主早前已經喺其他地方貼咗一層唔知名嘅平價PPF。用咗一段時間之後，膜面層開始溶膠、老化，加上長期日曬同溫差反覆，成塊車頭同引擎蓋佈滿密密麻麻嘅幼紋刮痕，透明度同光澤大幅下降。ZPAINT 嘅做法係拆走舊膜、做灰做平，再重新貼返一層光面（Gloss）TPU PPF。呢篇就借呢個真實 case，講清楚劣質PPF點解會出事，同埋修復要經過咩步驟。

入場車況

車主入場嗰陣，車頭引擎蓋喺光底下一睇就見到密密麻麻嘅幼紋刮痕，成塊膜面反光已經唔均勻，觸感亦冇原本膜料嗰種順滑感。呢啲刮痕唔係一兩條咁簡單，而係散佈成個表面，加上膜身老化之後透明度下降，睇落成塊車頭都蒙咗一層灰霧感，同新貼嗰陣嘅通透感完全係兩回事。

劣質PPF點解會溶膠刮花？

PPF 嘅表層塗層同耐候性係決定膜料壽命嘅關鍵。優質TPU膜料表層有自我修復能力，遇熱（曬車、暖水）幼紋會慢慢回復平滑；亦有較好嘅耐候塗層抵擋紫外線同溫差。相反，用料同塗層唔夠嘅雜牌膜，長期日曬雨淋加上香港嘅濕熱天氣，表層會提早老化變質，出現俗稱「溶膠」嘅現象——膜面摸落去帶黏手感、透明度下降，而且完全冇自我修復能力，一有幼紋刮花就永久留底，越積越多。

想再了解揀膜要注意咩，可以睇點解要揀好 PPF？平膜拆落嚟成塊車頭都係膠同點分真假PPF？香港常見「雜牌充當名牌」陷阱。

拆膜、做灰做平、重貼流程

  1. 評估膜況 — 先判斷刮痕深淺：表面幼紋有機會靠拋光解決，但如果好似呢單case咁大面積溶膠加深層刮痕，就要整塊拆膜處理
  2. 拆走舊PPF — 撕走已經老化嘅膜身，清走殘留嘅老化黏膠
  3. 打磨做灰做平 — 用打磨方式處理漆面表層殘留同刮痕，喺安全漆膜厚度範圍內將表面處理平整，呢步驟好講師傅經驗，力度控制唔好會磨穿
  4. 洗車同表面淨化 — 貼新膜前漆面必須完全乾淨，否則微塵會困喺膜同漆之間形成凸點
  5. 拆件 — 尾燈、車門手把、部分感應器蓋拆出嚟，確保膜料可以完整包邊
  6. 電腦裁膜 — 按 Model S 車身模具數據裁出每塊板件對應形狀
  7. 逐塊貼光面PPF — 由大面積板件（車頭、車頂、車門）開始，噴專用貼膜液輔助定位，再用刮板推走氣泡
  8. 加熱收邊 + 還原拆件 + 質檢 — 包實板件邊緣同弧位，尾燈手把裝返，逐面檢查氣泡翹邊

Model S 施工難點

今次呢單case除咗一般 Model S 全車PPF嘅難點之外，仲多咗一層「喺做灰做平之後貼膜」嘅挑戰：

  • 表面平整度要求更高 — 打磨後嘅表面如果唔夠均勻，貼膜之後隱約仍會睇到底下高低不平（俗稱橙皮紋），所以做灰做平呢步一定要夠仔細
  • 車頭同引擎蓋大弧面 — 面積大又帶弧度，貼膜時要避免拉扯過度令膜身變薄失去透明感
  • 感應器同鏡頭窗口 — 車頭雷達、環景鏡頭位置要預先確認範圍，裁膜時避開影響感應
  • 車門把手內縮設計 — 電動彈出式門把凹槠位細，手工裁膜同收邊要格外仔細先貼得平整

Before / After 對比

下面呢個對比滑桿用同一個車身角度拍攝：左邊係做灰做平嗰陣、舊膜拆走後嘅表面狀態；右邊係重新貼上光面PPF之後嘅完工效果。

完工之後，車身嘅淺藍紫色同倒影完全睇唔出之前刮花溶膠嘅痕跡——呢正正就係「拆膜、做灰做平、重貼」呢一整套流程嘅目標：由花到不能再花，返去到光面PPF先貼嗰陣嘅通透效果。

價錢參考

  • 局部PPF（車頭、倒車鏡、門邊等易中石位）— 適合預算有限，優先保護高風險位置
  • 光面全車PPF — 淨貼膜，唔涉及拆舊膜做灰做平
  • 拆膜 + 做灰做平 + 重貼全車PPF — 就好似今次呢部 Model S，因為舊膜已經溶膠刮花，要加多拆膜同打磨處理呢兩步，收費會比淨貼膜高
  • PPF + 陶瓷鍍膜 — 膜面加多一層鍍膜，撥水同疏水表現更好，打理更輕鬆
