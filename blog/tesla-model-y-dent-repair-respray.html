今次呢部係一部白色 Tesla Model Y，車主 WhatsApp 傳咗幾張相過嚟 — 右邊後門一條好長嘅凹陷、加兩處撞到見底漆嘅深傷、車側裙位（sill）都撞埋。呢類型損傷唔可以 PDR（免噴油凹陷修復）搞掂，一定要打拉、批灰、對色、焗噴油全套先做得返出廠效果。呢一篇 blog 詳細分享入場車況、施工流程同白色 Tesla 對色嘅難點。

入場車況 — 三個位置損傷

入場評估時我哋確認咗三個受損位置：

  • 後門長凹陷 — 沿住門把下方向後延伸，凹陷位有一條明顯嘅褶痕，即係鋼板已經變形，唔係單純表面損傷
  • 兩處深傷見底漆 — 凹陷中間有兩處撞到穿咗清漆同色漆層，見到灰色底漆甚至金屬層
  • 車側裙位變形 — 門檻下方嘅黑色塑膠飾條連同上方車身金屬都撞凹，膠邊有輕微翹起

凹痕修復 = PDR？點解今次要焗噴油？

好多車主一聽到「凹痕修復」就以為一定係 PDR — 唔使噴漆、平又快。實情係 PDR 有好嚴格嘅適用範圍。以下係兩者嘅分別：

項目 PDR 免噴油凹陷修復 凹痕修復＋焗噴油
適用損傷 純凹陷、漆膜完好、冇裂冇爆 凹陷加爆漆、見底漆、見金屬、變形褶痕
做法 用工具從背面慢慢推、頂返平 打拉整平 → 批灰 → 打磨 → 底漆 → 面漆 → 罩清漆 → 焗爐烘乾
完工效果 原漆保留，冇色差風險 同新車一樣，但要靠對色技術避免接口位穿煲
時間 半日至一日 5–7 個工作日（連焗漆 cure 時間）

今次個 case 因為漆膜已經爆咗、露出金屬層，PDR 就算頂返平個凹，都補唔到爆咗嘅漆，一定要焗噴油。

施工流程 — 5 個階段

由入場到交車，全流程分 5 個階段：

  1. 拆件同保護 — 後門相關嘅飾條、內襯、把手、玻璃邊條要拆出嚟，避免噴漆時黐到；車窗、輪拱、車尾廂邊都要用遮蔽紙同膠紙密封。
  2. 打拉整平 — 用鈑金工具由內裡向外頂，配合外面手工打磨，一步步將凹陷同褶痕整返平。呢一步嘅目標係令表面同原本車身面板嘅弧度一致 — 唔係「差唔多平」就得。
  3. 批灰同打磨 — 打拉完唔會完全平，餘下嘅細位要用汽車專用膩子（putty）填平，再由粗砂紙一路打到 P800 至 P1500 嘅細砂紙，摸落無邊緣感。
  4. 底漆 → 面漆 → 罩清漆 — 呢一步入焗漆房，分三層施工，每層之間烘乾。Tesla Pearl White 呢隻珍珠白面漆要噴兩層先夠深度，最後再噴罩清漆做保護同鏡面效果。
  5. 焗爐烘乾 → 拋光 → 交車 — 全車入焗爐約 45 分鐘做加熱固化，出爐等油完全 cure（一般 24–48 小時），最後拋光去噴漆點粒、質檢對縫，先交車。

今次因為片段只提供咗入場同交車相，未有施工中嘅過程紀錄，但每個步驟我哋都會影相畀車主睇進度。

呢款車嘅特別難點：白色 Tesla 對色

白色車主聽到「補漆」通常都會問一句：「會唔會有色差？」呢個擔心係有道理嘅 — 白色反而係最考功夫嘅顏色之一：

  • Tesla Pearl White 唔係純白 — 佢係珍珠白，含雲母粒子，光線角度唔同會呈現冷暖差。
  • Batch code 差別 — 就算原廠色號一樣，出廠 batch 唔同都有微色差。
  • 陽光 vs 車庫燈 — 有啲舖只喺車庫日光燈下對色，出到街太陽底下即刻穿煲。

我哋堅持嘅做法：用電腦色卡對色系統掃描原車漆，加師傅目測比對，先落漆。噴嘅時候用「褪色技術」（fade painting）— 唔會硬切一半塊門，而係將新漆過渡到相鄰車身面板嘅自然折線位（車門邊框、輪拱線），令新舊漆之間有一段漸變區。呢個做法係接口位睇唔出嘅關鍵。

修復完再考慮嘅升級

好多車主整完鈑金焗漆之後會問一句：「有冇辦法保護新漆，唔想再撞到咁易花？」呢個問題我哋通常會俾三個選擇：

保護方式 效果 維持時間 邊個位最抵做
陶瓷鍍膜 硬度提升、抗小刮花、疏水疏油 1–3 年 全車一次過
PPF（隱形車衣） 物理性防撞防石擊、自我修復 5–10 年 車頭、後視鏡、車門把、輪拱、車側裙
局部貼膜 高風險位單獨保護，成本較低 3–5 年 車門把周圍、車側裙、後泵把上緣

今次呢個 case，車主考慮緊喺車側門把同車側裙位加做局部 PPF — 因為呢兩個位就係之前撞到嘅位，加層保護膜之後就算再輕微擦碰都唔會傷到新漆。

價錢參考

Tesla Model Y 凹痕修復＋焗噴油嘅價錢視乎損傷範圍、要唔要換件、對色複雜度而定。以呢個 case 為例，範圍涉及一塊後門加車側裙 — 屬於中型損傷。價錢級別大致係：

  • 輕微凹痕（純 PDR） — 由 HK$1,500 起，適合冇爆漆嘅小凹陷
  • 單一面板凹痕＋焗噴油 — 由 HK$3,500 起，例如一塊車門或者一塊翼板
  • 多位置凹痕＋焗噴油（今次個 case） — 由 HK$5,500 起，涉及超過一塊面板或者連帶飾條
  • 嚴重事故修復 — 需要換件同拆件，另行報價
