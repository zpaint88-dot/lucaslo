Tesla Model S · 大撞修復完整紀錄

ZPAINT 編輯部·事故修復·閱讀約5分鐘

今次呢個 case 係一部 Tesla Model S — 車主晚上撞咗車頭，泵把、燈罩、水箱框架全部撞爛，拖車入場嗰晚車身仲有大範圍嘅刮花同凹陷。呢一篇 blog 就係想同大家 share 由拖車入廠、拆到見骨、修復中期到最後交車嘅完整過程。事故車修復唔係「噴翻返」咁簡單 — 涉及鈑金、換件、色調配、烘乾、質檢一整條流程。

第一階段：拖車入場

車主當晚 WhatsApp 聯絡我哋，直接叫拖車送嚟深水埗店。夜晚見到部車：前泵把整個爆脫、右前輪拱撕裂、頭燈框穿窿、水箱冷卻系統露出。撞擊力大到連車頭嘅結構橫樑都有變形。

Tesla 嘅事故車修復同一般車唔同：

  • 電池同高壓系統要先確認未受損，唔可以隨便通電
  • Autopilot 相機同雷達拆完裝返之後要重新校準
  • 鋁合金車身要用特定拉伸工具，唔可以用普通鐵車拉直方法

我哋第一步係全車 scan、影相入 file、幫車主申報保險。

第二階段：拆件見骨

確認唔涉及高壓電同氣壓系統受損之後，開始拆件。前泵把、頭燈、水箱框、防撞樑、部分內裡塑膠件都要拆出嚟 — 呢一步嘅目的係：

  1. 睇清楚點打 — 有時外觀睇落只係泵把爛，拆完先發現內裡防撞樑扭曲
  2. 分辨換件 vs 修件 — 有啲鈑金件可以拉直修返，有啲一撞就要成件換
  3. 清潔基層 — 修復前所有粘合面要磨去舊漆同銹跡

今次個 case 我哋換咗前泵把總成、頭燈框、防撞樑，鈑金上有 4 個位要打拉直 — 主要係前輪拱同 A 柱下方。全部完成先入下一步。

第三階段：修復中期（Refit + Paint Prep）

換件裝返之後，開始準備噴漆。呢個階段係最花時間，因為：

  • 新泵把出廠時係灰色底漆，需要打底、上原廠色再罩清漆
  • 舊車身有一部分要打磨去舊漆同轉折位，然後過渡到新件
  • 色調配係關鍵 — Tesla 灰色其實有幾個 batch code 差別，接口位如果調唔靚，光線下即刻穿煲

我哋用電腦色卡對色系統 + 老師傅目測雙重確認，之後噴槍師傅入焗漆房分層施工：底漆 → 面漆 → 罩光層，每層之間烘乾。呢個過程要 2-3 日。

另一部同期修復嘅深藍 Model S

差唔多同一時期我哋處理咗另一部深藍色 Model S — 車尾嚴重撞擊，尾泵把、尾玻璃、後尾廂框都要拆到齊。呢個部分係修復範圍更廣嘅例子。

第四階段：組裝 + 交車

焗漆完等油完全 cure（一般要 24-48 小時），開始裝返所有拆下嘅件：頭燈、Tesla T logo、輪弧內襯、後視鏡、感應器等等。每一件裝完都要對位置、對縫隙 — 呢個係最考驗師傅細心程度嘅步驟。

裝完之後，車入洗車位做清潔同去油，再入質檢。

今次由拖車入廠到交車一共 約兩星期（視乎入件時間），車主收車嗰陣覺得同新車一樣 — 唔會見到接口位、唔會見到色差、唔會有噴漆點粒。呢個係我哋想達到嘅標準。

Tesla 事故車修復需要留意咩？

  • 唔好隨便揀便宜舖 — Tesla 鋁車身、電池、感應器嘅處理都要專門知識
  • 用原廠件 vs 副廠件 — 我哋一律建議用原廠件，尤其係燈組同水箱系統，副廠件配合度會差
  • 保險理賠 — 我哋幫客處理拖車證明、拆件相、修復報價，方便向保險公司申請
  • 校準 Autopilot — 修復完頭燈框、bumper 或者換過相機，一定要做校準先可以還車

價錢參考

Tesla 事故車修復嘅價錢視乎撞擊嚴重程度、換件範圍、鈑金複雜度而定。今次個 case 收費由 HK$25,000 起（唔連換原廠件費用），實際報價要車主 WhatsApp 傳現場相俾我哋，或者拖車入場之後我哋現場評估。輕微碰撞（局部補漆同泵把換件）由 HK$3,500 起。詳細可以睇價目表。
