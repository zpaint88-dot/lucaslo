Tesla Model S 沙板撞爛，切割、燒焊、批灰再噴油

呢部紅色 Tesla Model S 撞咗後門同沙板（沙鈑），後輪前面嗰截撞到變形、摺曲，漆面都甩埋。呢種程度已經唔係執吓鈑、補吓灰就搞掂，要切走爛位、燒焊新件，再批灰、噴油追返原色。呢篇講吓成個過程，同埋點樣判斷架車要執鈑定要切割。

入場車況

  • 後門下半 — 有凹位同刮痕，反光見到成塊門板起波浪。
  • 沙板（後輪前面） — 撞到變形、摺曲，漆面甩晒見底。
  • 門同沙板交界 — 縫位撞歪，邊位扭曲。
  • 車底邊 — 近車裙位置都撞到變形。

執鈑定切割？點揀

唔係所有凹位都要切。要睇撞得幾深、有冇摺曲，同埋傷唔傷到骨位：

做法適合咩情況點做
鈑金執返凹位圓滑、鐵冇摺曲、冇裂由裏面頂返出嚟或者拉返平，再批灰噴油
切割燒焊新件沙板撞到摺曲、變形，執唔返原本線條切走爛位，燒焊新件，再打磨、批灰、噴油
換成塊件可以拆落嚟嘅板件（例如車門）損傷太大換件之後噴返同色，配返隙位

沙板同車門唔同，係焊死喺車身上面，唔可以好似車門咁成塊拆落嚟換。撞到摺曲嘅鐵，就算硬執返，金屬已經拉薄、線條都會走樣，之後批好厚灰先遮得住，日後易爆灰、裂紋。所以呢部車揀咗切割燒焊。

施工流程

1. 切走爛位

先拆走車裙同周邊配件，將沙板撞爛嗰截切走，切位要整齊，方便之後駁新件。

2. 燒焊新件

新件對好位之後逐點燒焊上車，焊點沿住接口一路做。黑色嗰部分就係新駁上去嘅件。

3. 批灰、打磨

焊口打磨平之後批灰，填平接位同細凹，等乾透再磨，令沙板線條同原車一樣。

4. 入噴房噴油

做好底漆，其餘位置用膠紙同遮蓋膜包好，入噴房噴紅色同清漆。

難做嘅位

線條要對返原車

Model S 後門同沙板之間係一條長斜線，新件焊上去之後，條線要同後門邊位平行，隙位要均勻。差少少，反光一照就見到條線唔順。

紅色追色

紅色係最考追色嘅顏色之一，深淺同光線角度唔同都會睇到色差。要先調色試板，對住原車比啱先噴，噴完再同隔離板面對比。

常見問題

沙板撞凹，係咪一定要切割換件？
唔一定。細凹、冇傷到骨位，通常鈑金執返、批灰噴油就得。好似呢部 Model S 咁，沙板邊撞到變形、摺曲，執唔返原本線條，先會切走爛位，燒焊新件。我哋會睇咗車先講邊個做法啱。

切割燒焊之後，會唔會睇得出？
燒焊位之後要打磨、批灰、做底漆，再噴油。工序做足，接位會收喺漆面下面，睇唔到焊口。呢部車完工嘅相可以睇到，後門同沙板反光順返，見唔到焊位。

紅色車噴油難唔難追色？
紅色係最考追色嘅顏色之一，深淺、閃粉同光線角度唔同都會睇到色差。我哋會先調色試板，對住原車比啱先噴，再同隔離板面睇有冇分色。

沙板撞爛可唔可以行保險？
如果有買全保，撞車損傷一般可以向保險公司申請。我哋可以幫手影拆件相、出報價單，同保險公司溝通。詳細流程可以睇我哋嘅保險理賠攻略。

價錢參考

沙板維修要睇撞得幾深、要唔要切割、新件同噴油範圍，冇得一口價。一般分幾級：

  • 鈑金執返＋局部噴油 — 凹位圓滑，冇摺曲
  • 切割燒焊＋批灰噴油 — 沙板撞到變形，好似呢部 Model S
  • 多塊板件一齊處理 — 車門、沙板、車裙都撞到
